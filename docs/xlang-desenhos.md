# xlang-desenhos

Drawings in a watercolor / colored-pencil style, generated as SVG strings for chat and web output.

```xlang
<import name="xlang.desenhos"></import>
<print>{desenhoCasa()}</print>
```

## Functions

| Function | Returns | Description |
|---|---|---|
| `desenhoCasa(semente?)` | SVG (`XLangHtml`) | A yellow house with a red scale roof, chimney with smoke, blue windows with a flower box, arched door, bushes, flowers, mushrooms, butterflies and clouds. The optional `semente` (finite number) changes the flowers, the pencil hatching and the sky blotches. Default seed: `11`. |

## Notes

- The SVG is **generated by code**, not stored. The module is small and is downloaded only when a program imports it.
- It only uses the tags and attributes accepted by `sanitizeHtml`: no `<ellipse>` (ellipses are drawn as `<path>` arcs) and no `opacity` (transparency uses `fill-opacity` / `stroke-opacity`).
- The root `<svg>` carries `class="ld"` and `viewBox="0 0 400 262"`, so a host page can recognize it as a drawing and add a paper/pencil texture filter on top.
- Errors: a `semente` that is not a finite number throws `desenhoCasa: "semente" must be a finite number.`

## Adding a new drawing

1. Add a builder function in `modules/xlang-desenhos.js` that returns an `<svg>` string using only whitelisted tags/attributes.
2. Register it with `R.register('desenhoNome', ...)`.
3. Document it in the table above.
