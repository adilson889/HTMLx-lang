What is XLang?

XLang turns HTML into a programming language. Write variables, functions, loops, classes and logic using simple tags that anyone who knows HTML can read and understand.

No new syntax. No build step. No compiler. Runs directly in the browser.

---

Why XLang?

Most languages separate "what you see" from "what runs". XLang does not separate them — the logic lives inside the page itself and reads/writes directly to the elements that are already there.

---

Get Started

1. Import the interpreter via CDN.
2. Write your program inside div[data-xlang].
3. Open the .html file in a browser. Done.
